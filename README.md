# ai_to_ai_loops

Replication and extension of Hintze, Proschinger Åström & Schossau (2026), "Autonomous language-image generation loops converge to generic visual motifs" (*Patterns* 7, 101451), followed by selection-rule arms that test whether the SDXL↔LLaVA loop can be steered away from its attractors.

Start with `CLAUDE.md` (working rules) and `SPEC.md` (arms, parameters, gates). Predictions are pre-registered in `predictions.md`; departures from Hintze are logged in `DEVIATIONS.md`.

Large data (`runs/`, `logs/`, `data/`) is git-ignored.
